# APSE scientific regression: ALMA MOUS uid://A001/X121/X46c

The FITS images are **not** committed. The first invocation downloads four MFS science / PB pairs to `~/.cache/apse/uid___A001_X121_X46c`. Subsequent runs reuse them. CASA is required locally; this test is **not** part of network-free CI.

```bash
cd ~/Projects/alma-point-source-extractor
source .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests -p 'test_*.py' -v
apse regression --casa /usr/local/bin/casa
```

If the data are already in the repository's ignored `data/` directory:

```bash
apse regression --offline --data-dir data/uid___A001_X121_X46c --casa /usr/local/bin/casa
```

**Important: no validated reference exists yet.** The command will run all four SPWs and exit code 2 until a verified legacy reference is supplied. To generate a candidate (not a reference):

```bash
apse regression --offline --data-dir data/uid___A001_X121_X46c --casa /usr/local/bin/casa --write-candidate /tmp/apse-regression-candidate.json
```

Run the original v0.1.0 implementation independently on the same FITS pairs, verify each SPW and the combined catalog, and commit the **compact** resulting reference as `tests/reference/mous_A001_X121_X46c.json` with provenance (original git SHA, CASA version, image SHA256 hashes, extraction parameters, UTC creation date, and source matching method). The candidate generated by v0.2.0 **must not** be accepted automatically as ground truth.

Comparison is per-SPW: raw and filtered counts, ICRS coordinates (0.05 arcsec), integrated flux, error and peak brightness (2% relative or 1 microJy absolute), point classification. These are provisional tolerances; establish justified limits after observing reproducibility of the legacy implementation across supported CASA versions. Comparing against one old run is not proof of correctness. For robust validation, include independent science sanity checks and compare the combined output against the union of per-SPW outputs.

Downloaded data and CASA intermediate files stay outside Git. Network and archive availability make this a local on-demand integration test, not a mandatory PR gate.
